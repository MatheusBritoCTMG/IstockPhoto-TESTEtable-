# 🧪 IstockPhoto — Projeto de Teste com Tabelas

Projeto escolar desenvolvido para praticar o uso de tabelas HTML (`<table>`, `<tr>`, `<td>`) e o controle de espaçamento na tela.

## 📋 Sobre o projeto

Este projeto tem caráter de treino, criado com o objetivo de fixar conceitos fundamentais de estruturação de páginas web usando tabelas, explorando alinhamento, espaçamento e organização de conteúdo em células.

## 🛠️ Tecnologias utilizadas

- **HTML** — estrutura da página, com foco em tabelas (`td`, `tr`)
- **CSS** — estilização e ajuste de espaçamento

## 🎯 Objetivo de aprendizado

- Praticar a criação de tabelas em HTML
- Entender o comportamento de células (`td`) e linhas (`tr`)
- Trabalhar espaçamento (padding, margin) para melhorar a organização visual da página

## 🎓 Contexto

Projeto feito como exercício em sala de aula, com foco no aprendizado prático de HTML e CSS.
